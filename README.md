# 구매 예측 실험실

공동연구자가 한 제품의 예상 구매자 수와 우선 제안 대상을 먼저 기록하고, 모형을 본 후 최종 판단을 남긴 뒤 실제 결과를 여는 한국어 웹 앱입니다. 일반 접속은 가상의 유자 곡물칩·자두 탄산수로 연습할 수 있습니다. 연구용 집계에는 연구자가 전달한 링크 또는 오프라인 파일로 접근합니다.

## 1. 실행

별도의 자바스크립트 패키지 설치 없이 Python 3에서 `python3 build.py`를 실행하고 `dist/index.html`을 브라우저로 여세요. 웹으로 보려면 `python3 -m http.server --directory dist 8000`을 실행해 로컬 주소를 엽니다. 웹 화면은 현재 브라우저에서 동작합니다. 인터넷 연결 없이 파일을 여는 경우 검토 기록은 JSON으로 내려받을 수 있습니다.

## 2. 연구 사례와 평가

1. 평가할 출시를 고르고 모형을 보기 전 예상 구매자 수와 선정 기준을 저장합니다.
2. 예측 방법, 목표 고객 비중, 초기에 결과를 관측한 타인의 수를 바꿉니다. 질문창에서 지원하는 질문의 뜻을 고릅니다. ‘내가 만든 문항으로 패널 조사하기’에서 구매 여부·최소 수요·구매 이유를 골라 제품별 문항을 만들고 패널에 묻습니다. 행동 문항은 기록 구매확률로 답하고 구매 이유는 실제 후속 인터뷰 후보로 남깁니다.
3. 조언 후 예상과 기준을 저장하고 실제 기록 구매를 엽니다. 이미 성적표를 보았거나 결과부터 연 사례는 가린 판단 비교에서 구분합니다.
4. 검토 의견은 브라우저에 임시로 보관합니다. 참여자가 동의하고 제출하면 암호화된 회신을 보내며, 파일로 연구자에게 돌려줄 수도 있습니다.

앱에서 미리 계산한 확률의 개별 베르누이 합을 이용해 패널 구매자 수를 다시 모의할 수 있습니다. 관측 누락과 모형 자체의 불확실성은 별도 평가 대상입니다. 공저자 화면에는 집계와 근거만 넣습니다.

## 3. 자체 연구판 만들기

`web/`에는 화면·스타일·질문 분류기가 있습니다. `build.py`의 기본 예시는 인공 자료입니다. 연구자는 `products`, `methods`, `rows`, `cohorts`, `primary`, `version`을 제공하는 자체 집계 JSON을 사용할 수 있습니다. 예시는 `plain_demo` 함수에서 확인할 수 있습니다. 32바이트 키를 base64url 형식으로 앱 소스 트리 밖에 저장하고 `cryptography`를 설치한 뒤 아래 명령을 실행합니다.

```sh
python3 build.py --study aggregate.json --key-file /private/location/study.key --offline reviewer.html
```

웹에는 암호문만 배포합니다. 연구자는 키를 URL의 `#study=` 뒤에 붙인 링크를 검토자에게 전달합니다. 오프라인 출력은 접근권한이 있는 사람에게 직접 제공하는 평문 집계입니다. 컴퓨터에 저장된 개인별 패널 데이터와 복호화 개인키는 배포 대상에서 제외합니다.

## 4. 회신과 확장

접수처가 지정된 연구판에서는 RSA-OAEP와 AES-GCM으로 각 회신을 암호화합니다. 같은 제출을 재시도하면 같은 암호문 지문을 사용합니다. 연구자용 `collect.py`는 권한 있는 Firebase CLI 계정과 로컬 키로 회신을 읽고, 고정된 정답을 이용해 가린 전후 판단과 의견을 집계합니다. 온라인 접수처를 사용하지 않는 연구에서는 JSON 파일을 받을 수 있습니다. 브라우저 방문자의 질문은 로컬 분류기로 해석합니다. `api_examples.py`로 공개 예문만 저가 언어모델에 보내 인터뷰 문항 후보를 시험할 수 있습니다.
